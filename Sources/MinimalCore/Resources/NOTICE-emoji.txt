Keybase emoji shortcode data

emoji-shortcodes.json is derived from emojiRevCodeMap, selecting the first
canonical shortcode for every Unicode sequence. It contains 1,875 entries.
emoji-aliases.json contains all 1,911 exact names in upstream emojiCodeMap,
including legacy aliases. Names absent from this snapshot are not built-ins.

The Go source was converted to an ASCII-escaped JSON dictionary. No executable
upstream code, images, image URLs, or renderer are included. Keybase's generator
uses emoji-datasource-apple data; only its scalar-to-shortcode output is included.
